# 通用演示：无隐私、抽象案例

## 输入

```text
法域：中国大陆某地
类型：合同纠纷
阶段：诉前协商
用户身份：付款方
目标：要求对方退款或继续履行
事实：用户称与对方达成一项服务交易，已付款。对方未按约定时间完成服务，之后多次表示会处理，但一直拖延。现在对方称双方没有明确约定完成时间，也不同意全额退款。
证据：付款记录、聊天记录、服务说明截图、对方延期回复、用户催告记录。
```

## Agent 处理示例

### 1. 一句话案件地图

用户基于服务交易关系，主张对方未按约定履行服务义务，要求退款或继续履行；对方可能抗辩未约定明确期限、已部分履行或用户要求过高。

### 2. 初步争点

| 争点 | 类型 | 证明责任 | 证据 |
|---|---|---|---|
| 双方是否存在服务合同关系 | 事实/法律 | 用户先证明 | 付款、聊天、服务说明 |
| 是否约定履行期限或可推定合理期限 | 事实/法律 | 用户先证明，对方可抗辩 | 聊天、服务说明、催告 |
| 对方是否未履行或迟延履行 | 事实 | 用户先证明 | 催告、对方延期回复 |
| 用户是否有权退款或要求继续履行 | 法律 | 需结合具体规则 | 合同内容、履行状态 |
| 退款金额如何计算 | 金额 | 用户主张部分需证明，对方抗辩部分需说明 | 付款、已履行内容 |

### 3. 证据缺口

- 服务内容和完成期限是否清楚。
- 对方是否已经部分履行及履行价值。
- 用户是否发出过明确催告及给过合理期限。
- 对方拖延原因是否可归责。

### 4. 合法提问示例

| 目标 | 问题 | 价值 |
|---|---|---|
| 确认关系 | 你方是否确认已收到该项服务费用？ | 锁定收款和交易关系 |
| 确认期限 | 当时服务说明中的完成时间，你方理解是否适用于本次交易？ | 锁定期限或解释矛盾 |
| 确认迟延 | 截至某日，该服务是否仍未全部完成？ | 锁定未履行状态 |
| 确认原因 | 你方认为未完成的具体原因是什么？ | 评估是否可归责 |
| 确认方案 | 你方是否能在某日前完成，若不能，是否同意退还未履行部分费用？ | 促成解决或保留证据 |

### 5. 法官视角

裁判者可能重点看：交易关系是否成立、约定内容是否明确、对方履行到什么程度、用户是否催告、退款金额是否有依据。单纯说“对方不诚信”价值较低；付款、聊天、催告和履行结果更关键。

### 6. 下一步

1. 保存完整聊天记录和付款凭证。
2. 整理服务说明、约定期限和对方延期回复。
3. 发送中性事实确认和催告信息，要求对方在明确期限内履行或提出退款方案。
4. 根据对方回复更新矛盾矩阵，再决定投诉、调解或起诉。
```
