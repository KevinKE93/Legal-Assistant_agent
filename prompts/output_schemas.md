# 输出模板总览

## 0. 通用 i18n 与最终汇总规则

- 默认使用用户输入的主语言输出标题、表格字段、文件夹名和最终总结文件名。
- 中文输入必须使用中文事项目录名和中文总结文件名，不得默认翻译成英文 slug。
- 法律名称、法条标题、合同原文、证据备注、对方原话和用户原始短语可保留原文。
- 工作底稿文件名保持稳定英文，例如 `plan.md`、`case.md`、`analysis.md`、`advice.md`。
- 最终总结文件必须面向用户阅读，逐项读取并综合工作底稿后重写，不得只复制 `analysis.md`。
- 事项目录默认使用 `work/<date>_<本地化事项名>/`。
- 禁止创建 `work/cases/`。
- 复杂事项最终汇总必须包含 `.md` 和同名 `.pdf`；若无法生成 PDF，必须说明阻塞原因。
