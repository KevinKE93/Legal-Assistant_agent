# Skill：案例参考与规则学习

## 适用场景

用户希望查找类似案例、学习裁判思路、比较胜败因素、提取可用于文书或谈判的规则时使用。

## 目标

1. 设计可执行的检索关键词。
2. 区分法规、指导案例、类案、裁判观点和文章评论。
3. 提炼案例中的事实相似点、差异点和裁判理由。
4. 防止误用案例或编造引用。

## 输入

- 法域。
- 案件类型。
- 核心事实。
- 争点。
- 用户请求。
- 对方抗辩。

## 工作流

### 1. 提取检索要素

从案件中抽取：

- 法律关系关键词。
- 行为关键词。
- 损害关键词。
- 抗辩关键词。
- 证据关键词。
- 程序关键词。

示例结构：

```text
法律关系 + 行为 + 损害 + 抗辩 + 证据
```

### 2. 检索优先级

优先级建议：

1. 现行法律法规、司法解释、官方规则。
2. 最高级别或本法域高权威裁判规则。
3. 同地区、同案由、同争点、近年案例。
4. 专业文章和评论，作为辅助理解，不作为直接依据。

### 3. 案例相似性评分

| 维度 | 问题 |
|---|---|
| 法律关系 | 是否同类关系 |
| 核心行为 | 对方行为是否相似 |
| 损害类型 | 损害是否相似 |
| 证据结构 | 证据是否相似 |
| 抗辩类型 | 对方抗辩是否相似 |
| 程序阶段 | 一审、二审、再审、仲裁等是否可比 |
| 地区和时间 | 是否同法域、近年、规则未变 |

### 4. 提炼裁判规则

对每个案例提炼：

```text
案件事实 → 争点 → 法院认定 → 关键证据 → 裁判理由 → 可借鉴点 → 不可类比点
```

### 5. 引用规范

引用前必须核验：

- 案号。
- 法院。
- 日期。
- 裁判文书来源。
- 是否生效。
- 是否被改判、撤销或规则过时。
- 是否只是个案事实判断。

## 输出格式

```markdown
## 检索关键词
- 主关键词：
- 替代关键词：
- 排除关键词：

## 检索路径
1. 法规/司法解释：
2. 权威案例：
3. 同类案例：
4. 评论文章：

## 案例学习表
| 案例 | 法院/来源 | 争点 | 相似点 | 差异点 | 关键证据 | 裁判理由 | 可借鉴性 |
|---|---|---|---|---|---|---|---|

## 可迁移规则
1. 
2. 

## 引用风险
```

## 质量检查

- 不编造案例或案号。
- 不把单个案例机械套用为必然结果。
- 明确相似点和差异点。
- 涉及最新法规或案例时必须核验。
