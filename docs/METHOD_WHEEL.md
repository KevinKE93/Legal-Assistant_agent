# 法律分析方法轮

方法轮是可选参考，不是默认执行清单。使用时按任务复杂度取其中必要环节。

```text
范围约束
→ 目标与模式选择
→ 必要分析镜头
→ 事实/条款还原
→ 证据与来源状态
→ 争议焦点或条款风险
→ 对方/裁判者视角
→ 策略或文书
→ 会话结论 / 目标交付物
→ 按需复盘
```

## 1. 范围约束

确认法域、用户身份、目标、期限、敏感信息和高风险行为。涉及违法、虚假陈述、非法取证或隐私侵害时，拒绝危险部分并给安全替代。

## 2. 目标与模式选择

按 `docs/WORKFLOW.md` 选择最小模式：

- `Quick Answer`：只回答。
- `Matter Note`：维护 `matter.md`。
- `Deliverable`：生成目标文件。
- `Deep Case`：复杂案件才展开工作台。

## 3. 必要分析镜头

按 `docs/SKILLS.md` 选择镜头。镜头用于帮助判断，不是固定流水线。

常见组合：

- 合同审查：合同镜头 + 策略镜头 + 必要来源核验。
- 纠纷分析：事实镜头 + 证据镜头 + 证明责任镜头 + 策略镜头。
- 庭审准备：证据镜头 + 对方视角 + 裁判者视角 + 听证镜头。
- 法律研究：来源镜头 + 规则适用边界。

## 4. 事实/条款还原

区分：

- 用户陈述。
- 已有证据支持的事实。
- 对方可能争议的事实。
- 推断或法律评价。
- 合同原文和解释。

## 5. 证据与来源状态

每个关键判断都说明证据状态和来源状态。没有官方或权威来源时，不写成已核验结论。

## 6. 争议焦点或条款风险

只展开影响当前目标的焦点：

- 要证明什么。
- 谁承担证明责任。
- 当前证据够不够。
- 对方可能如何反驳。
- 该风险影响什么行动。

## 7. 对方/裁判者视角

复杂争议才加入：

- 对方最可能攻击的事实或证据。
- 裁判者最可能追问的问题。
- 哪些表达会扩大风险。

## 8. 策略或文书

建议必须落到动作：

- 谁做。
- 做什么。
- 为什么做。
- 触发条件。
- 产物是什么。

## 9. 会话结论 / 目标交付物

默认先在会话中给实质结论。用户要求文件时，再生成目标文件。用户明确要求 PDF 时，才执行 PDF 渲染。

## 10. 复盘

出现新证据、新程序节点、新合同版本、新报价或用户目标变化时，只更新受影响部分，不从头重做。
